# Iron Mind Mentoring — Tracker

Single-file web app (`index.html`) for running Iron Mind programmes. Open it in a browser or host it on GitHub Pages.

- **Dashboard**: active clients, an action list (missing baselines, check-ins due, gaps between sessions, safeguarding flags) and backup reminders.
- **Clients**: schools and academies plus private 1:1 clients. Each client has:
  - **Overview**: 6-week timeline, this week's question and challenge, to-dos.
  - **Baseline & Progress**:
    - mental self-rating for the programme (OWN IT 8 areas, START STRONG 6, PERFORM IT 5 C's) at baseline, week 3 and week 6
    - physical tests
    - the Wheel
    - school measurables
  - **6-Week Journey**:
    - weekly themes and challenges
    - 42-day daily-page tracker
    - PERFORM IT habit check
  - **Toolkit**: the five Robot Protocol tools and the client's Switch, process cue and performance identity.
  - **Sessions** (with private notes and a safeguarding flag), **Goals**, **Check-ins**, **Access & Links**, and a printable **Report**.
- **Workshops**: Robot Protocol pilot pipeline.
- **Programmes**: reference library.
- **Data & Settings**: backup and restore, import check-ins, your contact details, change your password.

## How check-ins reach you
Each student, parent and staff member gets their own link and password. After they submit, the page gives them a WhatsApp or email message containing a code (`IMM1.…`). Paste that message into **Data & Settings → Import a check-in**. Student ratings fill the mental baseline automatically.

## Data
Everything is stored in your browser's local storage, on your device only. Download a backup regularly from Data & Settings. Data from the previous tracker version is migrated automatically on first open.
